# 专注力训练小程序 — 设计文档

## 概述

一款微信小程序，包含 3 个专注力训练小游戏 + 打卡日历 + 用户系统。使用 uniapp-cli (Vue 3 + Vite + TypeScript) 开发，后端使用 uniCloud。

## 技术栈

| 维度 | 选择 |
|------|------|
| 框架 | Vue 3 + Vite + TypeScript |
| 状态管理 | Pinia |
| UI | uni-ui 官方组件 + 自定义游戏组件 |
| 后端 | uniCloud（云数据库 + 云函数） |
| 目标平台 | 微信小程序 |

## 路由设计

```
TabBar（底部 3 个 Tab）
├── 首页 (pages/index)       →  点击「开始训练」→  游戏选择 (pages/game-select)
│                                                      ├── 游戏1 (pages/game-number)
│                                                      ├── 游戏2 (pages/game-color)
│                                                      └── 游戏3 (pages/game-memory)
├── 日历 (pages/calendar)
└── 我的 (pages/mine)
```

游戏页面内部有一个介绍页 + 一个游戏页，通过组件切换实现（非独立路由）。

## 数据模型

### uniCloud 数据库

**users**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| _id | string | 自动 | |
| openid | string | 是 | 微信 openid |
| nickname | string | 否 | 微信昵称 |
| avatar | string | 否 | 头像 URL |
| phone | string | 否 | 手机号 |
| created_at | timestamp | 是 | 注册时间 |

**training_records**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| _id | string | 自动 | |
| user_id | string | 是 | 关联 users._id |
| game_type | enum | 是 | `number` / `color` / `memory` |
| score | int | 是 | 成绩（游戏1=秒数, 游戏2=正确数, 游戏3=通过1/不通过0） |
| result | enum | 是 | `pass` / `fail` |
| date | date | 是 | 训练日期 |
| created_at | timestamp | 是 | |

### Pinia Store

**userStore**: openid, nickname, avatar, phone, isLogin, login(), logout()

**trainingStore**: todayRecords[], calendarData{}, fetchRecords(), addRecord(), getStreak()

**gameStore**: currentGame, status(idle/playing/passed/failed), startGame(), endGame()

## 游戏设计

### 游戏 1 — 数字顺序点击

**主色**: `#C49B8B`

**流程**:
```
介绍页（规则+能力说明+开始按钮）
  ↓ 点击开始
游戏页:
  数字 1~25 随机排列成 5×5 网格
  30 秒倒计时启动，当前目标 = 1
  用户点击格子:
    ├── 点击 = 目标数字 → 格子变灰/消失，目标数字 +1
    │     └── 点到 25 → 游戏结束
    │           ├── 耗时 ≤ 30 秒 且 < 20 秒 → 及格
    │           └── 30 秒 ≥ 耗时 ≥ 20 秒 → 不及格
    ├── 点击 ≠ 目标数字 → 游戏失败
    └── 倒计时归零 → 游戏失败
```

**介绍页内容**:
- 规则: 1~25 随机排列在 5×5 网格中，按从小到大顺序依次点击，点错立即失败，30 秒内完成
- 训练能力: 视觉搜索速度、信息筛选能力、决策速度

### 游戏 2 — 颜色 Stroop 1 分钟挑战

**主色**: `#A8B5A0`

**流程**:
```
介绍页（规则+能力说明+开始按钮）
  ↓ 点击开始
游戏页:
  1 分钟倒计时启动
  循环:
    随机选文字(红/橙/黄/绿/青/蓝/紫) + 随机显示颜色(同上，但 ≠ 文字)
    大字展示该字
    3 个选项按钮: [文字本身] [实际颜色 ✓] [随机干扰]
    2 秒倒计时
    用户选择:
      ├── 选实际颜色 → 正确 +1
      ├── 选错 → 错误
      └── 2 秒超时 → 等同错误
  1 分钟到 → 结束，统计正确数
```

**介绍页内容**:
- 规则: 判断字的显示颜色（不是文字含义），每题 2 秒，1 分钟内尽可能多做
- 训练能力: 抗干扰能力、反应速度、选择性注意

### 游戏 3 — 数字记忆

**主色**: `#9BA8C0`

**流程**:
```
介绍页（规则+能力说明+开始按钮）
  ↓ 点击开始
展示阶段:
  从 1~25 随机生成 7 个不重复数字作为目标序列
  依次全屏展示每个数字 2 秒，间隔 0.5 秒
作答阶段:
  展示 1~25 的 5×5 网格
  用户按顺序点击 7 个数字:
    ├── 全部 7 个顺序正确 → 获胜
    └── 任意一次点击错误 → 失败
```

**介绍页内容**:
- 规则: 记住依次出现的 7 个数字及其顺序，然后在 5×5 网格中按顺序找出它们
- 训练能力: 短时记忆、注意力维持、顺序记忆

## 页面设计

### 首页（Tab 1）

- 用户头像 + 昵称
- 累计训练天数 + 今日训练时长统计卡片
- 「开始训练」大按钮 → 跳转游戏选择页
- 今日训练记录列表

### 日历页（Tab 2）

- 月选择器 + 日历网格
- 每个日期格子下方 3 个彩色圆点（红 #C49B8B=游戏1, 绿 #A8B5A0=游戏2, 蓝 #9BA8C0=游戏3），灰色=未完成
- 全部完成（3/3）时格子背景变为暖杏金渐变 + 白色微光动画，日期数字深棕 #8B6F5E
- 点击日期查看当日训练详情

### 我的（Tab 3）

- 用户头像、昵称、手机号
- 登录方式: 微信一键登录 + 手机号登录
- 累计统计: 总训练次数、总训练时长、各游戏最佳成绩

### 游戏选择页

- 3 个游戏卡片，各含图标、名称、简短描述
- 点击进入对应游戏介绍页

## 用户登录

- 微信一键登录（wx.login + 获取用户信息）
- 手机号登录（微信手机号授权）
- 静默识别: 首次进入用 wx.login 获取 openid 建立用户记录
